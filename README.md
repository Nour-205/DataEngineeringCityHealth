# DataEngineeringCityHealth


## General Project Description  

This project's goal is to compute indices included but not limited to : Greenery index, Air Quality index, ect... out of data retrieved from DataGrandLyon. The current datasets are : Tree position, Airquality,... 

These indices will be used then to suggest ways of improving the general health of the area. This will depend on the available variables in that moment.
